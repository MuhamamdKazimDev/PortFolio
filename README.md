# Portfolio (static site for GitHub Pages)

Files to upload: `index.html`, `style-v2.css`, `assets/` (folder).

## Put it online
1. Open your PortFolio repository on github.com.
2. Add file > Upload files. Drag in `index.html`, `style-v2.css` and the whole `assets` folder. Commit.
3. Delete the old Vue files in the repo (for example `package.json`, `src`, `vite.config.js`, `dist`) so they do not clash: open each file, press the bin icon, commit.
4. Settings > Pages > Build and deployment: "Deploy from a branch", your main branch, `/ (root)`. Save.
5. After 1 to 2 minutes open https://muhamamdkazimdev.github.io/PortFolio/ and press Ctrl+F5.

## Contact form (optional)
Get a free key at web3forms.com using your email, then replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html`. Until you do, the form stays hidden and visitors use the email button.
